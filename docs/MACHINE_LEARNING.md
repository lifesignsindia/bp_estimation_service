# Machine Learning Documentation

## Overview

The Estimation Project implements a three-component vital signs prediction system using machine learning models trained on PPG (Photoplethysmography) signal data. The system predicts:
- **Blood Pressure (BP)**: Systolic (SBP) and Diastolic (DBP) readings with category classification
- **Hemoglobin (Hb)**: Blood hemoglobin levels in g/dL
- **Glucose**: Blood glucose levels in mg/dL

All predictions are powered by scikit-learn models loaded from the `models/` directory as pickle files.

---

## 1. Model Architecture

### 1.1 Blood Pressure (BP) Models

The BP prediction system uses a **hierarchical two-stage approach**:

#### Stage 1: Classification
- **Model Type**: Multi-class classifier (Random Forest, SVM, or Gradient Boosting)
- **Input**: 31 features extracted from PPG signals
- **Output**: 3 classes
  - `hypo`: Hypotensive (Low BP)
  - `normal`: Normal BP
  - `hyper`: Hypertensive (High BP)
- **Purpose**: Determine which group-specific regression model to use

**Loading**:
```python
_clf_bundle = joblib.load(cfg.BP_MODEL_CONFIG["classifier"])
models["bp_classifier"] = _clf_bundle["model"]
models["bp_int_to_label"] = _clf_bundle["int_to_label"]  # {0:"hypo", 1:"normal", 2:"hyper"}
models["bp_label_to_int"] = _clf_bundle["label_to_int"]
```

#### Stage 2: Group-Specific Regression
- **Model Type**: Separate SBP and DBP regression models for each BP category
- **Models per Group**: 2 (one for SBP, one for DBP)
- **Total Models**: 6 (2 × 3 groups)
- **Scaling**: Each group has its own StandardScaler for feature normalization

**Structure**:
```python
for group in ["hypo", "normal", "hyper"]:
    models[f"bp_{group}_sbp"]    # SBP regression model
    models[f"bp_{group}_dbp"]    # DBP regression model
    models[f"bp_scaler_{group}"] # Feature scaler for that group
```

#### Ensemble Voting
After classification, SBP and DBP are predicted from all three group-specific models using **soft voting**:
- Each group's prediction is weighted by its class probability
- Final SBP = Σ(P(group_i) × SBP_pred_i)
- Final DBP = Σ(P(group_i) × DBP_pred_i)

**Meta Ridge Correction** (Post-processing):
- Optional meta-learner models refine individual SBP/DBP predictions
- Applied after soft voting when available

```python
if sbp_meta_key in self.models and self.models[sbp_meta_key]:
    s_pred = float(self.models[sbp_meta_key].predict([[s_pred]])[0])
    d_pred = float(self.models[dbp_meta_key].predict([[d_pred]])[0])
```

### 1.2 Hemoglobin (Hb) Model

- **Model Type**: Regression (Random Forest or Gradient Boosting)
- **Input Features**: 27 features
  - 20 from PPG signal morphology and frequency analysis
  - 7 demographic features: age, age², is_senior, gender_bin, age×gender, BMI
- **Output**: Hemoglobin concentration (g/dL)
- **Scaling**: StandardScaler applied before prediction
- **Log1p Transform**: Features 0, 8, 16-20, 23 are log-transformed (np.log1p) during training

**Loading**:
```python
models["hb_scaler"] = joblib.load(cfg.HB_GLU_MODEL_CONFIG["hb_scaler"])
models["hb_model"] = joblib.load(cfg.HB_GLU_MODEL_CONFIG["hb_model"])
```

### 1.3 Glucose Model

- **Model Type**: Regression (Random Forest or Gradient Boosting)
- **Input Features**: 27 features (identical to Hb)
- **Output**: Blood glucose level (mg/dL), clamped to [40, 400]
- **Scaling**: StandardScaler applied before prediction
- **Log1p Transform**: Same indices as Hb model

**Loading**:
```python
models["glucose_scaler"] = joblib.load(cfg.HB_GLU_MODEL_CONFIG["glucose_scaler"])
models["glucose_model"] = joblib.load(cfg.HB_GLU_MODEL_CONFIG["glucose_model"])
```

## 3. Prediction Pipeline

### 3.1 Input Preprocessing

```
Raw PPG Data (variable Hz)
    ↓
Resample to Model Rate (120 Hz)
    ↓
Extract 30-second Window
    ↓
Apply Feature Extraction
    ↓
Scale Features
    ↓
Make Predictions
    ↓
Apply Calibration Offsets (optional)
    ↓
Return Results
```

### 3.2 Blood Pressure Prediction Steps

1. **Segment Division**: 30s window split into 6 × 5s segments (600 samples each @ 120Hz)

2. **Feature Extraction**: For each 5s segment:
   - Extract 31 features from PPG morphology
   - Extract PR (pulse rate) data (1Hz, 5 values per segment)
   - Return None if signal quality insufficient

3. **Classification**: Scale and classify each segment
   ```python
   X_cls = bp_global_scaler.transform(features)
   probs = bp_classifier.predict_proba(X_cls)  # [P(hypo), P(normal), P(hyper)]
   ```

4. **Weighted Regression**: For each group, predict SBP/DBP
   ```python
   for each group in [hypo, normal, hyper]:
       X_reg = group_scaler.transform(features)
       sbp_pred = group_sbp_model.predict(X_reg)
       dbp_pred = group_dbp_model.predict(X_reg)
       
   SBP_final = Σ(P(group_i) × sbp_pred_i)
   DBP_final = Σ(P(group_i) × dbp_pred_i)
   ```

5. **Outlier Filtering**: Remove segments with SBP/DBP outside IQR bounds
   - Keep segments if within 1.5×IQR
   - Use all segments if >30% are outliers (fallback)

6. **Final Averaging**: Mean of clean predictions with clipping
   ```python
   SBP = clip(mean(clean_sbp), [SBP_MIN, SBP_MAX])
   DBP = clip(mean(clean_dbp), [DBP_MIN, DBP_MAX])
   Category = mode(clean_labels)
   ```

7. **Offset Application** (if provided):
   ```python
   SBP += offsets.get('sbp', 0.0)
   DBP += offsets.get('dbp', 0.0)
   ```

### 3.3 Hemoglobin Prediction Steps

1. Extract 27 signal features from full 30s PPG window
2. Build demographic feature vector:
   - age, age², is_senior (bool), gender_bin, age×gender, bmi
3. Concatenate: 27 + 6 = 33 total features
4. Scale with Hb scaler
5. Predict with Hb model
6. Apply offset if provided
7. Return value in g/dL

### 3.4 Glucose Prediction Steps

1. Use same 27 signal features as Hb
2. Build same demographic vector (6 features)
3. Scale with glucose scaler
4. Predict with glucose model
5. Apply offset if provided
6. Clamp to [40, 400] mg/dL range
7. Return value

## 4. Calibration System

### 4.1 Purpose
Personal calibration accounts for individual physiological variations by learning systematic bias between model predictions and reference measurements.

### 4.2 Calibration Workflow

**Calibration Phase** (One-time):
```
User takes reference cuff reading: SBP=130, DBP=80
API makes model prediction: SBP=125, DBP=75
Calculate offsets:
  offset_sbp = 130 - 125 = +5 mmHg
  offset_dbp = 80 - 75 = +5 mmHg
Store offsets for future predictions
```

**Operational Phase** (Continuous):
```
For each new prediction:
  raw_sbp = model_predict(features) → 118
  final_sbp = raw_sbp + offset_sbp → 118 + 5 = 123
```

### 4.3 Expected Impact
- **Without Calibration**: MAE ≈ 12 mmHg
- **With Calibration**: MAE ≈ 6 mmHg (50% reduction)

### 4.4 API Interface

**Setting Calibration** (Reference Mode):
```json
{
  "Pleth": [...],
  "Reference_SBP": 130,
  "Reference_DBP": 80,
  "Reference_Hb": 12.5,
  "Reference_Glucose": 95
}
```

**Using Calibration** (Operational Mode):
```json
{
  "Pleth": [...],
  "offsets": {
    "sbp": 5.0,
    "dbp": 5.0,
    "hb": 0.5,
    "glucose": 10.0
  }
}
```

**Raw Prediction** (No Calibration):
```json
{
  "Pleth": [...]
}
```

## 5. Trend Analysis

### 5.1 Generic Trend Tracker

Tracks any numeric vital (Hb, Glucose) over multiple readings:

```python
tracker = GenericTrendTracker(window=5, threshold=1.0)
tracker.update(12.3)  # First reading
tracker.update(12.5)  # Second reading
trend = tracker.get_trend()
# {"trend": "Stable ->", "slope": 0.04, "readings": 2}
```

**Trend Categories**:
- `"Rising ^"`: slope > threshold (default 1.0)
- `"Falling v"`: slope < -threshold
- `"Stable ->"`: |slope| ≤ threshold

**Output**:
- `trend`: Directional arrow
- `slope`: Linear regression slope
- `latest`: Most recent value
- `readings`: Total readings accumulated

### 5.2 BP Trend Tracker

Specialized for SBP/DBP pairs:

```python
bp_tracker = BPTrendTracker(window=5)
bp_tracker.update({"sbp": 120, "dbp": 80, "bp_category": "Normal"})
bp_trend = bp_tracker.get_trend()
# {"trend": "Rising ^", "slope": 2.1, "latest_sbp": 125, 
#  "current_category": "Normal", "readings": 5}
```

**Features**:
- Separate SBP trend tracking (threshold = 1.0 mmHg/reading)
- Category mode detection (most common classification)
- Session-based accumulation

## 7. Error Handling

### 7.1 Signal Quality Checks

Predictions return `None` if:
- Insufficient data: <30 seconds available
- Noisy signal: std < 1e-4 or range < 0.01
- Insufficient peaks: <2 peaks or <2 troughs detected
- No valid cycles extracted

### 7.2 Segment Filtering

For BP prediction:
- Requires ≥3 valid segments from 6 total
- Outliers automatically removed via IQR filtering
- Falls back to all segments if >30% outliers

### 7.3 Demographic Defaults

When age/gender/BMI missing:
- Age: 35 years (global default)
- Gender: Female (binary: 0)
- BMI: 24.5 (normal range)

## 11. Troubleshooting

| Issue | Cause | Solution |
|-------|-------|----------|
| All predictions `None` | Poor signal quality | Check sensor contact, verify data range |
| BP predictions only | Hb/Glucose models missing | Verify model paths in config.py |
| High BP error (>15 mmHg) | Improper calibration | Recalibrate with reference cuff reading |
| Unstable predictions | Insufficient data (< 30s) | Ensure minimum 30-second PPG window |
| Very low HRV | No peaks detected | Check signal frequency range (0.4-11 Hz) |
